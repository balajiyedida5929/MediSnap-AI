\# 💊 MediSnap AI



MediSnap AI is an AI-powered medicine information assistant that uses image recognition to analyze medicine images and provide easy-to-understand information.



\## 🚀 Features



\- Upload a medicine image

\- AI-powered medicine identification

\- Common uses of the medicine

\- Important safety information

\- Multiple language support

\- Optional questions about the medicine

\- Clear medical safety disclaimer

\- Simple and user-friendly Streamlit interface



\## 🛠️ Technologies Used



\- Python

\- Streamlit

\- Google Gemini Vision API

\- Google GenAI SDK



\## 🌐 Supported Languages



\- English

\- Telugu

\- Hindi

\- Tamil

\- Kannada

\- Malayalam



\## ⚙️ How It Works



1\. User uploads an image of a medicine.

2\. MediSnap AI sends the image to the Gemini Vision model.

3\. Gemini analyzes the medicine image.

4\. The application provides information about the medicine.

5\. The result is displayed in the selected language.



\## ⚠️ Disclaimer



MediSnap AI is intended for general educational information only. It does not provide medical diagnosis, personalized dosage, or medical prescriptions. Users should consult a qualified doctor or pharmacist for medical decisions.
